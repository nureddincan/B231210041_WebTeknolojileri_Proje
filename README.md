# Web Teknolojileri Dersi - 2024-2025 Bahar Dönemi Proje Ödevi

Bu proje, **Web Teknolojileri** dersi kapsamında bireysel olarak hazırlanmıştır.  
HTML, CSS, Bootstrap ve JavaScript teknolojileri kullanılarak tasarladığım; TMDB API Entegrasyonu ve Form Validation içeren, responsive tasarıma sahip kişisel web sayfam. 

## Proje İçeriği

- **Hakkında Sayfası:** Kendimi tanıttığım giriş sayfası (hobilerim, etkinliklerim ve ilgili görseller/linkler).
- **Özgeçmiş (CV) Sayfası:** Eğitim bilgilerimin yer aldığı ve semantik HTML etiketleri kullanılarak hazırlanmış bir sayfa.
- **Şehrim Sayfası:** Memleketim hakkında bilgiler içeren, başında/sonunda 4 resimlik bir slider barındıran bir sayfa.
- **Mirasımız/Takımımız Sayfası:** Şehrime ait kültürel bir eser hakkında bilgiler verilen bir sayfa.
- **İlgi Alanlarım Sayfası:** İlgi alanlarım doğrultusunda ücretsiz API kullanılarak veri çekilen bir sayfa (TMDB API).
- **Login Sayfası:** Kullanıcı adı ve şifre ile giriş yapılan, PHP ile kontrol işlemleri yapılan bir login sistemi.
- **İletişim Sayfası:** Form elemanları ile hazırlanmış, JavaScript ve bir popüler JS kütüphanesi (Vue.js) kullanılarak doğrulama yapılan bir iletişim formu.

## Kullanılan Teknolojiler

- **HTML5**
- **CSS3**
- **Bootstrap**
- **JavaScript**
- **PHP** (Login işlemleri için)
- **Vue.js** (İletişim formu doğrulaması için)
